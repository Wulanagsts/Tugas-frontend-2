## Deskripsi
Landing page katalog produk UMKM yang responsif dengan pendekatan **mobile-first**.
Halaman memuat 6 kartu produk (foto, nama produk, kategori, dan harga) dan dibuat dengan:
- HTML5 semantik
- CSS 
- Flexbox
- CSS Grid
- Media Query

## Cara Menjalankan:
1. download repository ini
2. Buka folder project di VS code.
3. Klik kanan "index.html", pilih **open with live server** (atau buka langsung di browser)
